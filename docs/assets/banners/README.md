# Banner concepts

Three original concepts use the same LCD-mark geometry as the GUI, plus the program name. No personal photographs or vendor artwork are used.

- `a-dark`: horizontal name, dark background, mint mark.
- `b-stacked`: two-line name with a neutral mark.
- `c-light`: horizontal name, light background, graphite mark.

PNG files are 1280 × 300 and render the bundled Outfit font consistently. SVG sources remain editable; font fallback can change text appearance in viewers without Outfit. Regenerate with `python examples/generate_banners.py` from an environment with the desktop dependencies installed. Original artwork is GPLv3-or-later; Outfit retains its OFL notice. Concept B was selected for the main README.
