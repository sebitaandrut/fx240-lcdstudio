# FX240 tray artwork

Application name: **FX240 LCD STUDIO**.

Original project artwork, selected by the user as concept B (LCD): a rounded cooler outline surrounding a circular display. The geometry is identical across dark, light, and fallback stroke variants. This is not an official manufacturer logo or a recovered vendor asset. It is separate from the upstream Lucide icon set and is licensed under GPLv3 or later with the original project code.

The variant is selected from the desktop color scheme, independently of the application's Dark/Light setting. The fallback uses a medium green when Qt cannot determine the desktop scheme.

The same geometry is used for the tray, application/window icon, and sidebar brand. Desktop icons follow the desktop scheme; the sidebar follows the application theme.
